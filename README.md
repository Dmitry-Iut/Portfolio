# Портфолио — Дмитрий Иутинский

Сайт-портфолио для GitHub Pages с четырьмя разделами:

| Папка | Раздел |
|---|---|
| `3d-modeling/` | 3D-моделирование (Blender) |
| `web/` | Web-проекты и браузерные игры |
| `figma/` | Figma и прототипы |
| `practice/` | Практика |

## Как добавить работу

Все работы описаны в одном файле — **`data/projects.js`**. Скопируй блок `{ ... }` в нужном разделе и заполни поля.

- Картинки и модели клади в папку `media/` нужного раздела, а в поле пиши путь от корня: `"3d-modeling/media/chair.jpg"`.
- **3D:** поле `model` — файл `.glb` (в Blender: *File → Export → glTF 2.0*, формат *glb*). На сайте модель можно крутить пальцем и мышью. `image` — превью-рендер.
- **Web:** `demo` — ссылка на работающий сайт, `code` — на репозиторий.
- **Figma:** `figma` — ссылка из кнопки *Share* (доступ «Anyone with the link»). Если `image` пустое, макет встроится прямо в карточку.

- **Практика:** поля `role`, `period`, `place` показываются строкой под названием — роль в команде, когда и где.

Если у работы несколько тегов, на странице раздела появятся фильтры.

## Как выложить на GitHub Pages

1. Создай репозиторий, например `portfolio` (или `dmitry-iut.github.io`, тогда сайт будет по корневому адресу).
2. Загрузи содержимое этой папки в корень репозитория.
3. *Settings → Pages → Source: Deploy from a branch*, ветка `main`, папка `/ (root)`.
4. Через минуту сайт откроется по адресу `https://<ник>.github.io/portfolio/`.

Сборка не нужна — это чистые HTML, CSS и JavaScript.
