# Фишка — каталог настольных игр

**Сайт:** https://dmitry-iut.github.io/Board_game_catalog/

## Что это

«Фишка» — сайт-каталог издательства настольных игр. Здесь собраны игры для семьи и компании: у каждой есть своя карточка с фотографиями и описанием.

## Для чего

- познакомиться с играми издательства и выбрать подходящую;
- открыть подробную карточку игры с каруселью фотографий;
- добавить понравившиеся игры в избранное или в корзину.

## Игры в каталоге

Уно, Мафия, Манчкин, Бункер, Бродячие города, Монополия, Свинтус, Подземелье: Ярость богини змей.

## Возможности

- светлая и тёмная тема;
- адаптивная вёрстка для телефона и компьютера;
- избранное и корзина;
- карусель из трёх фото в каждой карточке.

## Технологии

- HTML5 — структура страниц
- CSS3 — оформление и адаптивность
- JavaScript — карточки, корзина, избранное, переключение темы
- GitHub Pages — размещение сайта
