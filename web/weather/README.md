# Погода

Веб-приложение, которое показывает текущую погоду и прогноз на неделю для любого города. Карточка оформлена в стиле «стекла» (glassmorphism), а фон меняется в зависимости от погоды.

**Демо:** https://weather-psi-three-27.vercel.app

## Возможности

- **Погода по геопозиции.** При открытии приложение определяет ваше местоположение. Если доступа к геопозиции нет, показывается Москва.
- **Поиск города** по названию с выбором из списка найденных вариантов.
- **Текущая погода:** описание, температура, иконка, день недели и время замера.
- **Восход, закат и долгота дня.**
- **Вероятность осадков** на сегодня.
- **Влажность, «ощущается как» и скорость ветра** (м/с).
- **Прогноз на 7 дней** с максимальной и минимальной температурой.
- **Тема фона под погоду:** ясно, облачно, туман, дождь, снег, гроза, ночь.

## Технологии

- [React 19](https://react.dev) и [Vite](https://vite.dev)
- Чистый CSS, без UI-библиотек
- [Open-Meteo](https://open-meteo.com) для прогноза погоды и поиска городов (API без ключа)
- [BigDataCloud](https://www.bigdatacloud.com) для определения названия города по координатам
- Хостинг на [Vercel](https://vercel.com)

## Структура

```
src/
├── App.jsx     # интерфейс: поиск, текущая погода, прогноз

├── index.css   # базовые стили
├── main.jsx    # точка входа

```

## Данные

Прогноз: Open-Meteo (модели ECMWF, DWD, NOAA). Ключи API не нужны.
