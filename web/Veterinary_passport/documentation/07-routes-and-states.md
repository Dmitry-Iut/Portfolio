# 7. Таблица адресов и состояний

Маршрутизация — через hash (`#/...`), поэтому любой адрес можно открыть напрямую или обновить страницу.

## 7.2. Состояния страниц

| Страница | Состояние | Условие | Что видит пользователь |
|---|---|---|---|
| Главная | Есть проблемы | хотя бы одна прививка «скоро» или «просрочена» | Список «Требует внимания» с цветными статусами |
| Главная | Всё хорошо | все прививки актуальны | Сообщение «Все прививки актуальны 🎉» |
| Питомцы | По умолчанию | фильтры не заданы | Все 6 карточек, сортировка по имени, «Найдено: 6 из 6» |
| Питомцы | Отфильтровано | выбран вид / статус / введён поиск | Только подходящие карточки, счётчик обновлён |
| Питомцы | Пусто | ни одна карточка не подходит | «Никого не нашли. Попробуйте изменить фильтры.» |
| Питомцы | Сброс | нажата «Сбросить» | Фильтры по умолчанию + уведомление «Фильтры сброшены» |
| Питомец | Есть чип | `chip` заполнен | Номер чипа и кнопка «Скопировать номер чипа» |
| Питомец | Нет чипа | `chip = null` (Рыжик) | «Чип: нет», кнопки нет |
| Питомец | Чип скопирован | нажата кнопка | Уведомление «Номер чипа … скопирован» |
| Питомец | Статус прививок | худший статус | Бейдж «Прививки в порядке» / «Скоро ревакцинация» / «Прививка просрочена» |
| Хозяин | Один питомец | у хозяина 1 животное | Карточка без кнопок карусели |
| Хозяин | Несколько питомцев | 2 и более | Карусель с кнопками ‹ › |
| Прививки | Фильтр «Все» / «Актуальны» / «Скоро» / «Просрочены» | нажат чип | Активный чип зелёный, таблица отфильтрована, в чипе — количество |
| Прививки | Пусто | в выбранном статусе нет прививок | «Прививок с такими условиями нет.» |
| Прививки | Сортировка | выбрано значение | Строки по дате ревакцинации / сначала свежие / по питомцу |
| Меню (моб.) | Закрыто / открыто | нажат бургер | Иконка ☰ ↔ ✕, меню выпадает; закрывается при переходе |
| 404 | Неизвестный адрес | маршрут не найден | «Страница не найдена» и кнопка на главную |
