# Ветпаспорт — база домашних питомцев

**Сайт:** https://dmitry-iut.github.io/Veterinary_passport/

## Что это

Ветпаспорт — веб-сайт с базой домашних питомцев. У каждого хозяина есть своя карточка, а в ней — карусель его питомцев с фотографиями, кличками и основной информацией.

## Для чего

- хранить сведения о питомцах в одном месте, как в электронном ветеринарном паспорте;
- быстро находить нужного питомца и его хозяина;
- показать навыки вёрстки и работы с интерфейсом на HTML, CSS и JavaScript.

Проект сделан как учебная работа по дисциплине «Веб-разработка» (КГУ, «Высшая ИТ-школа»).

## Технологии

- HTML5 — структура страниц
- CSS3 — оформление и адаптивность
- JavaScript — карусель питомцев и интерактивные элементы
- GitHub Pages — размещение сайта
